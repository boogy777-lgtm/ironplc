============================
Network (IronLink) Reference
============================

The program :program:`ironlink` (:program:`ironlink.exe` on Windows) finds
IronPLC controllers on the network and shows the route to each. It only finds:
it opens no listening port, holds no session and never writes to a controller.
The editor and the other IronPLC programs connect to a controller themselves.
