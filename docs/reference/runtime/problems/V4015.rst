=====
V4015
=====

.. problem-summary:: V4015

A command arrived in a hot-edit phase where the protocol does not allow it —
for example ``testEdits`` while the candidate is already under test,
``acceptEdits`` while a test or untest is pending at the scan boundary, or
``cancelEdits`` while another swap is already queued. The online change controller is a
small state machine; each phase admits only the commands that cannot corrupt
its invariants, and the runtime refuses the rest.

Example
-------

A session tests a candidate and then asks to test it again:

.. code-block::

   {"command":"testEdits"}
   {"response":"ack"}
   {"command":"testEdits"}
   {"response":"error","vCode":"V4015","message":"operation not allowed in the current hot-edit phase"}

The refusal leaves the session exactly where it was: the candidate stays
active and the state is untouched.

To fix this error, consult ``getStatus`` and take the transition the current
phase offers: the ``edit`` field lists the commands the device allows now. While
``testEdits`` or ``untestEdits`` is pending at the scan boundary, wait for the
runtime to apply the swap. While the candidate is under test, the exits are
``untestEdits``, ``cancelEdits`` (a logic-only edit: the device reverts to the
original at the next scan boundary and discards the candidate there, and
answers once) and ``assembleEdits``.
