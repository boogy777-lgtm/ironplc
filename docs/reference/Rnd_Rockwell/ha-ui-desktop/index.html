HA Redundancy UI — nine control-composition philosophies

Same semantics and demo behavior, one shared core (mockup-core.js): every variant shows the same HA data and exposes swap / death / degrade / calibrate / invalidate / reset, ping/pong +1 / +1000, TakeoverReady and budget badges. The difference is how controls are composed. Vendor names are neutral comparison labels only; no assets or logos.

Variants

1 · IDE / Docks

Device tree; HA areas as document tabs; docked Events + Inspector; row context menus; property-grid Apply.

Open

2 · Hierarchy + Modal Dialogs

Organizer tree → properties page; dangerous actions gated by modal dialogs with OK / Cancel / Apply; ribbon.

Open

3 · Panes + Grids + Operator

Data grids with multi-select bulk actions; operator lamp screen with one big takeover button.

Open

4 · Task Portal + Wizard

Task checklist navigation (Overview → Admission → Calibration → Qualification → Takeover → Events); takeover wizard.

Open

5 · Dual View (physical / logical)

One dataset, two projections: hardware tree vs function tree; editors and message dock stay docked.

Open

6 · Basic / Advanced Disclosure

Simple mode: lamps + big one-click actions. Advanced reveals grids, timing terms, event ledger, risky commands.

Open

7 · Topology Diagram First

The diagram is the UI: click a controller, link, or module block; its context panel opens beside the topology.

Open

8 · Solution Shell

Solution explorer, tabbed documents, docked Properties + Error List, Output / State monitor; error list drives attention.

Open

9 · Dashboard + Drawers

Icon rail navigation, KPI cards per HA area, slide-over drawers with detail and actions; touch-sized targets.

Plain HTML/CSS/JS over file:// — no build step.
Online edit mode (all nine): while connected the editor is a read-only monitoring surface (live values, click selects); a modification attempt opens a confirmation — Yes enters Pending Local, No stays in monitoring — then Accept → Staged, Test → Testing, Assemble → Clean at the new generation; Discard/Cancel return to monitoring. Offline = free editing, no confirmation.
Identical semantics in all nine: role/IP config, standalone/redundant toggle, admission/permit indicator, Manual swap, Simulate primary death, Degrade/Restore link, Run calibration, qualification invalidation, Reset; ping/pong +1 / +1000 counters; epoch/generations; TakeoverReady and budget verdicts; per-module owner/ARM state, T contributions, limiting device.
