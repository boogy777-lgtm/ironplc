=====
E0011
=====

.. problem-summary:: E0011

The ``address`` of a ``tcp`` connection profile is not an IPv4 dotted-quad,
an IPv6 literal, or an RFC 1123 hostname, or an ``address`` was set on a
``stdio`` profile (which spawns a local session and has no network target).

**Solutions**:

1. **Fix the address**: use a dotted-quad such as ``192.168.1.10``, an IPv6
   literal such as ``fd00::1``, or a hostname such as ``plc-01``.

2. **stdio profiles**: remove the ``address`` (and ``port``); the profile
   only needs the ``program`` the local session loads.

3. **Check for typos**: hostnames contain letters, digits and hyphens only;
   a label cannot start or end with a hyphen.

The extension checks the form of the address when it reads the setting. It
does not resolve a hostname and it does not contact the device, so a
well-formed address that does not answer is reported later as E0013.

A hostname is at most 253 characters, and each label between the dots is 1
to 63 characters. A dotted name made of digits only is read as an IPv4
address, so ``999.1.1.1`` is rejected: an octet cannot be greater than 255.

Example
-------

.. code-block:: json

   { "name": "line-1", "transport": "tcp", "address": "plc-01.plant.example" }
