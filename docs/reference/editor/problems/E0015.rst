=====
E0015
=====

.. problem-summary:: E0015

The device no longer matches the project baseline this workspace was last
verified equal against: another engineer edited the device, or the device
rebooted into a different state. Deploying local edits over unknown device
state is refused (fail-closed).

**Solutions**:

1. **Re-sync the project from the device**, rebuild, and connect again —
   the baseline is refreshed the moment your build is verified on the
   device.

2. **Review before building**: while the baseline is stale the connection
   stays up for monitoring, but Build is refused until the project matches
   the device again.

The baseline is recorded when the device accepts a build from this
workspace. It holds the generation counters the device reports and the hash
of the container this workspace built. Before the extension sends anything,
it compares the state the device reports now with that record. A workspace
that has no baseline yet (the first deploy to a device) is not checked.
