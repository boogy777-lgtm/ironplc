=====
P0003
=====

.. problem-summary:: P0003

The compiler encountered an unexpected token while parsing the source text.

This error occurs when the parser encounters text that is not valid IEC 61131-3 syntax.

Example
-------

The following code will generate error P0003:

.. code-block::

   TYPE
       CUSTOM_STRUCT : STRUCT
           NAME: BOOL;
           $ : BOOL;   (* Error: Invalid character '$' *)
       END_STRUCT;
   END_TYPE

The tokenizer encountered the ``$`` character, which starts no token of IEC 61131-3 text. A character that is a token but is not valid where it stands (the ``&`` of ``STRUCT&``, which is the ``AND`` operator) is a :doc:`syntax error <P0002>` instead.

To fix this error, remove the invalid character and use valid IEC 61131-3 syntax:

.. code-block::

   TYPE
       CUSTOM_STRUCT : STRUCT
           NAME: BOOL;
           FLAG : BOOL;   (* Correct: No invalid characters *)
       END_STRUCT;
   END_TYPE
